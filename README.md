# 📹 Video & Audio Streaming Surveillance System

Python ကို အသုံးပြုပြီး တည်ဆောက်ထားတဲ့ Real-time ဗီဒီယိုနဲ့ အသံ ပေးပို့နိုင်တဲ့ စနစ်ဖြစ်ပါတယ်။

## ✨ Features
* **Real-time Video:** OpenCV ကို သုံးပြီး 640x480 resolution နဲ့ ပို့လွှတ်ပါတယ်။
* **Synchronous Audio:** PyAudio နဲ့ အသံကို တစ်ပြိုင်တည်း ထုတ်လွှင့်ပါတယ်။
* **Multi-threading:** Video နဲ့ Audio အတွက် သီးခြား thread များ သုံးထားလို့ latency နည်းပါတယ်။
* **GUI:** Tkinter နဲ့ အသုံးပြုရလွယ်ကူအောင် ပြုလုပ်ထားပါတယ်။
